Does Exa return the new answer after it changes?

Agents ask about things that changed last week. If search returns last month's answer, the agent repeats it with confidence. This is an independent test of what Exa already ships: 58 queries whose answer changed between 14 Sep and 14 Oct 2026, run on 14 Oct across search types and date settings.

Short answer: yes, almost always. In every setting the current answer appeared in the top 10 for 89 to 100% of queries and ranked first 74 to 100% of the time.

What stood out

  • The published-date filter raises precision (held-out P@10 .74 to .77) but drops undated official pages, about 65% of results. Releases from the same morning were missed under it.
  • maxAgeHours: 0 gave the highest or tied-highest top-1 rate, at about 10 s per call. Instant and fast returned in about 0.4 s.
  • The one unfiltered stale case was an official help page from April still listing the old Disney+ price.

All checks are code, checked against 551 hand labels (22 false positives, 0 misses). 361 calls, $2.44 as reported by Exa. Small samples, one day. Data, cache and harness: github.com/sivaratrisrinivas/exa-freshness-eval.
